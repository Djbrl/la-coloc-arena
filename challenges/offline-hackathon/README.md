# Hackathon: works without a connection

**Kind:** hackathon · **Prize:** 50 000 FCFA · **Title:** Hackathon ace (As du hackathon)

## The task

In one week, build a small app that keeps doing its main job when the connection drops: a shop till, a to-do list,
a phrasebook, a bus timetable. It saves what it can locally and catches up when the network is back.

Put everything in `challenges/offline-hackathon/<your GitHub login>/`.

## A good pull request

- Only touches your own folder.
- Has a README: what it does, how to run it (one command), and how you tested it with the network off.
- Teams are welcome: one pull request, and the README says who did what.
- Uses only permissive licences (no GPL, AGPL or LGPL).

## Points

A merged entry the judges label `arena:entry` scores **30** (merged before Monday 00:00 UTC). Open: 0 (waiting). Closed without a merge: 0.
