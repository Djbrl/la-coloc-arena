# Coding challenge: tests for the examples

**Kind:** coding challenge · **Prize:** 15 000 FCFA · **Title:** Test pilot (Pilote d'essai)

## The task

Pick an example app in [`examples/`](../../examples) with few tests, and add the ones that would catch its next bug:
the edge cases, the wrong inputs, the thing that broke once already.

## A good pull request

- Tests only: it doesn't change how the app behaves.
- Each test says in its name what it checks, and fails if that breaks (try it: break the code, watch it fail).
- Runs with the app's usual test command, and the README of the app says how.

## Points

A merged pull request the judges label `arena:entry` scores **20** (merged before Monday 00:00 UTC). Open: 0 (waiting). Closed without a merge: 0.
