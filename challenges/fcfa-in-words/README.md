# Coding challenge: amounts in words

**Kind:** coding challenge · **Prize:** 15 000 FCFA · **Title:** Wordsmith (Fine plume)

## The task

Write a function that takes a whole amount of FCFA (0 to 999 999 999) and writes it in words, in French, the way it
goes on a cheque: `1250` → `mille deux cent cinquante francs CFA`.

Any language. Put it in `challenges/fcfa-in-words/<your GitHub login>/`, with its tests.

## A good pull request

- Passes every case in [`cases.txt`](cases.txt) (one per line: the amount, a tab, the words).
- Has a test that reads `cases.txt`, and says how to run it.
- Clear code beats clever code: a reviewer should follow it in five minutes.
- Only touches your own folder.

## Points

A merged solution the judges label `arena:entry` scores **20** (merged before Monday 00:00 UTC). Open: 0 (waiting). Closed without a merge: 0.
