# Hackathon: for the market

**Kind:** hackathon · **Prize:** 50 000 FCFA · **Title:** Night owl (Couche-tard)

## The task

In one week, build a tool a market trader would use every day: today's prices, what's left in stock, who owes what,
a reminder to restock. Small and useful beats big and unfinished.

Put everything in `challenges/market-hackathon/<your GitHub login>/`.

## A good pull request

- Only touches your own folder.
- Has a README with a screenshot, and runs with one command.
- Teams are welcome: one pull request, and the README says who did what.
- Uses only permissive licences (no GPL, AGPL or LGPL). No brand logos.

## Points

A merged entry the judges label `arena:entry` scores **30** (merged before Monday 00:00 UTC). Open: 0 (waiting). Closed without a merge: 0.
